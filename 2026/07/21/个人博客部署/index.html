第八步（可选但强烈推荐）：绑定自己的域名

如果你有自己的域名（比如在阿里云、腾讯云买的），可以在 GitHub 仓库的 Settings → Pages → Custom domain 里填上你的域名，然后在域名服务商那里添加一条 CNAME 记录指向 你的用户名.github.io。这样你就可以用 www.你的域名.com 来访问了。
